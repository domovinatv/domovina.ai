2. **Migracije** (`katalog/migrations/`, `wrangler d1 migrations` format). Tablice: `brands` (id, host), `channels` (brand, slug, youtube_channel_id, name, tier, lang, avatar, processed_count, latest_published_date), `episodes` (brand, id = YouTube ID, channel_slug, title, title_hr, published_date, duration_seconds, tier, lang, magisterium_score, flags bitmask kao `p` u `home.json`, updated_at), `ingest_runs`. Indeksi za svaku buduću rutu: `(brand, published_date DESC, id)`, `(brand, channel_slug, published_date DESC, id)`, `(brand, tier, latest_published_date DESC, slug)`. Zapiši u odluku zašto je svaki indeks tu. Test: migracije se primijene na lokalni D1 i `EXPLAIN QUERY PLAN` za tri glavna upita koristi indeks (ne `SCAN`).
3. **Parseri** (`katalog/src/input/`). Tipovi za stvarne ulaze, samo polja koja trebamo: `channels/data/index.json` (`ChannelSummary`), `channels/data/<slug>.json` (listing kanala; polje `pipeline`), `data/<id>/info.json` (`id`, `title`, `channel`, `channel_id`, `upload_date`, `duration`), `data/<id>/summary.json` (`title`/`title_hr`, sažetak), `data/<id>/episode.json` (popis datoteka). Oblik provjeri na stvarnim datotekama, ne iz memorije: `curl -s https://cdn.domovina.ai/channels/data/index.json | head -c 2000`, a Dart modeli u `packages/podcast_core/lib/models/channel_index.dart`, `channel_detail.dart`, `home_snapshot.dart` su ugovor kakav app danas čita. Pravila: decimalan `duration` postoji (memorija „X/Twitter source episodes”), polje koje nedostaje je `null`, nikad izmišljena vrijednost.
4. **Fixturei** (`katalog/test/fixtures/`). 3 Tier 1 kanala (listing skraćen na ≤ 20 epizoda), 5 `_unlisted` epizoda iz 5 različitih kanala (`info.json` + `summary.json` + `episode.json` s CDN-a; ID-eve uzmi iz `/Volumes/DOMOVINA2TB/fetch_domovina_tv_output/_unlisted/*.info.json`), isječak `../fetch.domovina.tv/data/podcasts_registry.json` s njihovim kanalima (+ jedan kanal kojeg NEMA u registryju, za S2). Skripta `npm run fixtures:refresh` ih ponovno izvuče. Fetch repo i CDN se samo čitaju.
