## Pipeline zastavice iz imena datoteka (odluka 202)

Pravila `generate_channel_index.js` (redci ~359–371) preslikana na R2 imena daju isti `flags` kao
listing za 3411 od 3412 Tier 1 epizoda; razlika je `MGLq9v3AtvE` (`domovina_tv`): R2 ima
`article.magisterium.json`, listing `has_magisterium: false`. `video_count == len(videos)` u svih 52.

```bash
python3 -c "
import json,re,collections
F='../../fetch.domovina.tv/'; B=F+'storage/meta/channels/data/'
d=json.load(open(F+'.r2_keys_cache.json'))['sizes']
files=collections.defaultdict(set)
for k in d:
  m=re.fullmatch(r'data/([^/]+)/(.+)',k)
  if m: files[m.group(1)].add(m.group(2))
BITS=['has_transcript','has_diarized','has_summary','has_article','has_magisterium','has_translation_en','has_summary_en','has_article_en','has_magisterium_en']
def kf(f):
  p={'has_transcript':'diarized.srt' in f,'has_diarized':'diarized.srt' in f,'has_summary':'summary.json' in f,'has_article':'article.json' in f,
     'has_magisterium':'article.magisterium.json' in f or 'article.magisterium_batch.json' in f,'has_summary_en':'summary.en.json' in f,
     'has_article_en':'article.en.json' in f,'has_magisterium_en':'article.magisterium.en.json' in f}
  p['has_translation_en']=p['has_summary_en'] and p['has_article_en']
  return sum(1<<i for i,b in enumerate(BITS) if p[b])
same=diff=vc=0
for c in json.load(open(B+'index.json'))['channels']:
  L=json.load(open(B+c['id']+'.json')); vc+=L.get('video_count')!=len(L['videos'])
  for v in L['videos']:
    lf=sum(1<<i for i,b in enumerate(BITS) if (v.get('pipeline') or {}).get(b))
    if lf==kf(files[v['id']]): same+=1
    else: diff+=1; print(c['id'], v['id'], lf, kf(files[v['id']]))
print(same, diff, 'video_count!=len:', vc)"
```

## `summary.json` Tier 2 epizoda (odluka 206)

Od 253: `source.upload_date` 185 × `YYYY-MM-DD`, 68 × `YYYYMMDD`; `source.channel` 194 × `_unlisted`,
55 × `_varijante`, 2 × `subclub`, 1 × `launched`, 1 × `domovina_tv`. Tri ID-a nemaju `info.json`
ni na CDN-u ni u key cacheu (`6dcab9c9837`, `cd7ac05aabf` → `subclub`; `eab99cbaefd` → `launched`;
`source.duration_seconds` null).

```bash
cat > /tmp/s2-summary.mjs <<'JS'
import { readFileSync } from "node:fs";
const F = "../../fetch.domovina.tv/", B = F + "storage/meta/channels/data/";
const d = JSON.parse(readFileSync(F + ".r2_keys_cache.json", "utf8")).sizes;

for (const c of JSON.parse(readFileSync(B + "index.json", "utf8")).channels)
  for (const v of JSON.parse(readFileSync(B + c.id + ".json", "utf8")).videos) art.delete(v.id);

    const u = s.source?.upload_date;
    const f = u == null ? "null" : /^\d{8}$/.test(u) ? "YYYYMMDD" : "YYYY-MM-DD";
    fmt[f] = (fmt[f] ?? 0) + 1;
    ch[s.source?.channel] = (ch[s.source?.channel] ?? 0) + 1;

console.log(ids.length, fmt, ch);
```

## Razrješavanje kanala (odluke 203–205)

Ulaz: `info.json` 250 od 253 Tier 2 epizode (preuzeti u `/tmp/s2-t2/`). `extractor`: 249 × `youtube`,
1 × `twitter`. Po `channel_id`: 14 je jednoznačno Tier 1 kanal (`index.json`), 0 dvosmisleno
(Tier 1 kanali s istim ID-em), 31 nema registry unosa (→ 28 kanala `yt-…`/`x-…`).
Registry s više unosa po `channel_id`: bez pravila `type: channel` ostaje 36 epizoda bez kanala, s
njim 22:

| YouTube kanal (`info.channel`) | epizoda | registry unosi |
|---|---|---|
| TV Jadran | 8 | 5 playlista |
| Jutarnji list | 4 | 5 playlista |
| HRT vijesti | 4 | 3 playliste s `parent_slug: hrt` (`hrt` je drugi `channel_id`) |
| Anze Tomic | 3 | 3 playliste |
| VTV Televizija | 1 | 3 playliste |
| RTL | 1 | 3 playliste |
| NOVA TV | 1 | 2 playliste |
| *riješeno pravilom `channel`:* Podcast Inkubator 6, Nova Eva 5, Poslovni dnevnik 2, VIDA 1 | 14 | 1 `channel` + playliste |

22 / 253 = 8,7 %, ispod praga rizika 10 %. Popravak: unos `umbrella` ili `channel` u registryju za
tih 7 `channel_id`-eva (fetch sesija).

```bash
mkdir -p /tmp/s2-t2
python3 -c "
import json,re
F='../../fetch.domovina.tv/'; B=F+'storage/meta/channels/data/'
d=json.load(open(F+'.r2_keys_cache.json'))['sizes']
art={m.group(1) for k in d if (m:=re.fullmatch(r'data/([^/]+)/article\.json',k))}
t1=set().union(*[{v['id'] for v in json.load(open(B+c['id']+'.json'))['videos']} for c in json.load(open(B+'index.json'))['channels']])
print('\n'.join(sorted(art-t1)))" > /tmp/s2-t2/ids.txt
xargs -P 6 -I{} sh -c 'curl -sf -o /tmp/s2-t2/{}.info.json https://cdn.domovina.ai/data/{}/info.json || true' < /tmp/s2-t2/ids.txt
python3 -c "
import json,glob,re,collections
F='../../fetch.domovina.tv/'
reg=json.load(open(F+'data/podcasts_registry.json'))['podcasts']
idx=json.load(open(F+'storage/meta/channels/data/index.json'))['channels']
UC=re.compile(r'^https://(www\.|m\.)?youtube\.com/channel/(UC[0-9A-Za-z_-]{22})(/|$)')
t1=collections.Counter(m.group(2) for c in idx if (m:=UC.match(c.get('youtube_channel_url') or '')))
byc=collections.defaultdict(list)
for e in reg:
  if e['youtube'].get('channel_id'): byc[e['youtube']['channel_id']].append(e)
def pick(c,wc):
  if len(c)==1: return c[0]
  rules=[lambda e:e['youtube'].get('type')=='umbrella']+([lambda e:e['youtube'].get('type')=='channel'] if wc else [])+[lambda e:'parent_slug' not in e]
  for f in rules:
    x=[e for e in c if f(e)]
    if len(x)==1: return x[0]
infos=[json.load(open(f)) for f in sorted(glob.glob('/tmp/s2-t2/*.info.json'))]
for wc in (False,True):
  amb=collections.Counter(i.get('channel') for i in infos if t1.get(i.get('channel_id'),0)==0 and byc.get(i.get('channel_id')) and pick(byc[i['channel_id']],wc) is None)
  print('channel' if wc else 'bez channel', sum(amb.values()), dict(amb))
print(len(infos), sum(t1.get(i.get('channel_id'),0)==1 for i in infos), sum(t1.get(i.get('channel_id'),0)>1 for i in infos),
      sum(t1.get(i.get('channel_id'),0)==0 and not byc.get(i.get('channel_id')) for i in infos), collections.Counter(i.get('extractor') for i in infos))"
```
