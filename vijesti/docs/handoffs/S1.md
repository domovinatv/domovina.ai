# S1: kostur, CDN loader, shema, LlmClient

Polazni commit: `5e5c652` (plan, TODO, handoffi). Koda još nema. Odluke od **100**.

Paket:

1. **Kostur.** `vijesti/package.json` (Node 22, ESM, TypeScript strict), eslint, vitest, `npm run check` = tsc + eslint + vitest. Vlastiti `package-lock.json`. `vijesti/.gitignore` (`node_modules`, `.env`, `.cache/`). Kratak `vijesti/README.md`: što je, kako se pokreće, linkovi na plan i TODO.
2. **CDN loader** (`engine/cdn/`). Tipovi i parseri za `data/<id>/info.json` (samo polja koja trebamo), `summary.json`, `article.json` (`iterations[].sections[]`), `episode.json` (popis datoteka), `diarized.srt` (s `[SPEAKER_XX]`), `words.json`, i channel listing `channels/<slug>.json`. Pravila iz korijenskog `CLAUDE.md` vrijede i ovdje: datoteku koje nema u `episode.json` ne traži; 404 s CDN-a ponovi jednom s cache-busterom (`?cb=<5-min bucket>`), jer CDN cachira 404. Kesh na disku u `vijesti/.cache/`. Ugovor polja provjeri na stvarnim datotekama, ne iz memorije: `docs/2026-10-06-titlovi-rijec-po-rijec.md` (words.json), `docs/2026-08-26-episode-processing-status.md` (faze).
3. **Fixturei** (`engine/test/fixtures/<id>/`). 5 stvarnih epizoda: jedna s `words.json`, jedna bez, jedna engleska (izlaz pipelinea je hrvatski i za nju), jedna s više od 3 govornika, jedna duga (> 2 h). Skrati na ≤ 200 kB po epizodi (prvih ~15 min transkripta + odgovarajuće sekcije), ali zadrži stvarni oblik. Skripta `npm run fixtures:refresh` ih ponovno izvuče.
4. **Shema baze** (`db/migrations/`). Shema `vijesti`: `moments`, `stories`, `story_moments`, `articles`, `article_versions`, `article_sources` (verzija ↔ trenutak), `corrections`, `runs` (svaki LLM prolaz: model, broj poziva, tokeni, trošak). Migracije gore i dolje, testovi na PGlite. Polja za trenutak barem: video_id, start_ms, end_ms, speaker, quote, quote_check (`exact` | `fuzzy` | `srt_only` | `failed`), topics, entities, score, run_id.
5. **`LlmClient`** (`engine/llm/`). Sučelje `generate({prompt, schema}) → validiran JSON`, pravi Gemini klijent (ključ `GEMINI_API_KEY` iz `vijesti/.env`, model iz konfiguracije), lažni klijent koji vraća snimljene odgovore iz fixturea. Svaki poziv se broji u `runs`. Izlaz koji ne prolazi shemu je greška, ne tihi popravak.

Gotovo kad: `npm run check` zelen, `skipped 0`; loader čita svih 5 fixturea bez greške; migracije idu gore i dolje na PGlite; nijedan test ne ide na mrežu (provjeri da test prolazi s isključenom mrežom ili s `fetch` koji baca).
